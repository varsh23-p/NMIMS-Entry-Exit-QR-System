🎯 Problem Statement

College campuses rely on manual paper registers at gates — prone to errors, forgery, and zero real-time insight. This app replaces it with a QR code-based digital system where the security guard scans a student's QR card, and entry or exit is automatically logged to Firebase Realtime Database with timestamps. Students and admins get instant access to attendance history, campus status, and registration data.

3 User Roles & Their Screens
🎓
Student
SAP ID + Phone Login
  • Login with SAP ID & registered mobile number
  • View personal profile (name, branch, year, residence)
  • View DC status (Discipline Committee type & count)
  • Profile photo displayed from Firebase (Base64)
  • Attendance stats: Total / Present / Absent days
  • Logout back to main scan screen
🛡️
Security Guard
Firebase Email/Password Auth
  • Email & password login via Firebase Authentication
  • Scan QR card — auto detects 11-digit SAP ID
  • Smart entry/exit: 1st scan = Entry, 2nd scan = Exit
  • Shows student name, branch, year, residence, DC info
  • Displays current campus status (Inside / Outside)
  • Full entry/exit history with dates & timestamps
  • Manual search by SAP ID
  • Register new students directly from dashboard
⚙️
Admin / Registration
Student Onboarding
  • Register student with SAP ID, name, phone, branch
  • Year selection via spinner (FY / SY / TY / Final)
  • Residence type: Hosteller or Day Scholar
  • DC type: DC (with count) or Non-DC
  • Upload student photo from gallery (JPEG compressed)
  • Photo stored as Base64 string in Firebase
  • Auto form clear after successful registration

How It Works
01

Admin Registers Student

Fills SAP ID, name, phone, branch, year, residence, DC type & photo → saved to Firebase under "Students/{sapId}"

02

Security Guard Logs In

Uses Firebase email/password auth to access the Security Dashboard

03

QR Scan at Gate

Guard taps Scan → camera opens in portrait mode → scans student's QR card → app extracts 11-digit SAP ID

04

Auto Entry / Exit Log

If no record today → writes entry_time. If entry exists → writes exit_time. Shows student info & campus status instantly

05

Student Views Dashboard

Student logs in with SAP ID + phone → sees profile, photo, DC info & attendance stats
